# Simon Musyoki — Portfolio

Enterprise portfolio for a Data Scientist | Statistician | AI & Analytics Engineer at Controltech Limited.

## Stack

- Next.js 16 (App Router)
- TypeScript
- Tailwind CSS v4
- Lucide icons

## Scripts

```bash
npm install
npm run dev
npm run build
npm start
```
